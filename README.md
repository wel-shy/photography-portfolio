# Welshy Photography

Photography portfolio built with React, TypeScript and [Vite](https://vite.dev).

## Available Scripts

### `npm start`

Runs the app in development mode at [http://localhost:3000](http://localhost:3000).

### `npm run build`

Type-checks the project and builds it for production to the `build` folder.

### `npm run preview`

Serves the production build locally.

### `npm test`

Runs the tests with [Vitest](https://vitest.dev).

### `npm run lint` / `npm run format`

Lints with ESLint and formats with Prettier.

## Configuration

Environment variables live in `.env` and must be prefixed with `VITE_` to be exposed to the app.
